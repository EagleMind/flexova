# Before you start

This quick reference summarises the **Aurora P2** field manual. Keep it with the pump.

::: {custom-style="Warning"}
Never run the pump dry for more than 30 seconds.
:::

::: {custom-style="Warning"}
Keep children and animals away while the engine runs.
:::

![The front panel, with the start switch on the left and the pressure gauge on the right](panel.png)

## Daily checks

1. Oil level between the marks.
2. Strainer clean and fully submerged.
3. Hose couplings tight.
