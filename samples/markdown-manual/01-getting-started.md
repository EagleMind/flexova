# Getting started

The **Aurora P2** is a portable water pump for field teams. This manual covers setup,
[daily operation](02-operation.md) and [maintenance](03-maintenance.md#service-intervals).

> [!NOTE]
> Read the whole chapter before the first start. It takes about ten minutes.

## What is in the box

| Item            | Quantity | Notes                       |
| --------------- | -------: | --------------------------- |
| Pump unit       |        1 | Pre-filled with oil         |
| Suction hose    |        1 | 5 m, with strainer          |
| Tool kit        |        1 | See [tools](#tools-needed)  |

## Tools needed

- A 13 mm spanner
- A funnel
- [ ] Fuel (unleaded, 95 octane)
- [x] This manual

![Front panel of the Aurora P2, with the start switch on the left and the pressure gauge on the right](images/panel.png "The front panel")

## First start

1. Place the pump on level ground, at most 3 m above the water.
2. Connect the suction hose and submerge the strainer.
3. Open the fuel valve and set the choke.
   - In cold weather, close the choke fully.
   - Above 25 °C, leave it half open.
4. Pull the starter cord firmly.[^cord]

> [!WARNING]
> Never run the pump dry for more than **30 seconds**. The seal overheats and must be replaced.

[^cord]: If the engine does not start after five pulls, see [troubleshooting](02-operation.md#troubleshooting).
