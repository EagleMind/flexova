# ADR-0014: Rendering decisions from M2 (viewer budget, ids, static HTML format)

- **Status:** Accepted, 2026-11-02.
- **Supersedes:** ADR-0007's "Size budget: ≤ 6 KB gzipped". Everything else in ADR-0007 stands.

## Decisions

| #   | Decision                                                                                                                                                                                                                                                                                                                                                                                    | Why                                                                                                                                                                                                                                                                                                                                |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **The viewer's size budget is 8 KB gzipped** (CI fails above it; currently about 7.2 KB).                                                                                                                                                                                                                                                                                                   | The 6 KB figure came from a prototype without MathML, multi-chapter id namespacing and link rewriting, a table of contents, `<picture>`/audio, the theme attribute, size limits or error UI. Re-encoding the generated allowlist saved nothing (gzip already compresses JSON well), so getting under 6 KB meant dropping features. |
| 2   | **One environment-free rebuild routine** (`@flexova/viewer/render`) serves both the viewer (DOM) and `@flexova/html` (strings in Node). Its allowlist is **generated from the profile** and committed, and a test fails if it drifts.                                                                                                                                                       | One sanitizer to audit instead of two.                                                                                                                                                                                                                                                                                             |
| 3   | **Ids are namespaced per document** (`d<n>-<id>`), and links are rewritten to in-page anchors (`02.xhtml#x` → `#d2-x`).                                                                                                                                                                                                                                                                     | Chapters rendered into one page would otherwise collide on ids, which is legal across separate EPUB documents, and cross-chapter links would break.                                                                                                                                                                                |
| 4   | **Unknown elements are unwrapped** and their text kept; forbidden elements are dropped with their subtree. Rendering stops at the profile's nesting limit.                                                                                                                                                                                                                                  | Implements spec sections 9 and 10. The depth limit prevents stack exhaustion on hostile nesting.                                                                                                                                                                                                                                   |
| 5   | **Tables are wrapped in a focusable, labelled scroll region** (`role="region"`, `tabindex="0"`, `aria-label` from the caption).                                                                                                                                                                                                                                                             | Wide tables scroll inside themselves instead of widening the page on phones, and keyboard users can scroll them, as axe's `scrollable-region-focusable` rule requires.                                                                                                                                                             |
| 6   | **Chapters use `content-visibility: auto`** in both renderers.                                                                                                                                                                                                                                                                                                                              | 1,000-page benchmark: static page load fell from 2.2 s to 0.23 s, and from 8.7 s to 0.93 s at 4× CPU slowdown.                                                                                                                                                                                                                     |
| 7   | **`.flexova.html` embeds its package reversibly.** Images and audio appear once, as `data:` URIs tagged with `data-flexova-src="<path>"`. All other entries travel as a deflated ZIP, base64-encoded in `<script type="application/vnd.flexova.package+json" id="flexova-package">` as `{format: "flexova-html", version: 1, names, zip}`. `fromHtml()` recovers every entry byte for byte. | Fulfils ADR-0006: a trusted reader can extract and verify the original. Compressing the text entries cut the 1,000-page benchmark page from 7.8 MB to 4.4 MB.                                                                                                                                                                      |
| 8   | **Static pages carry a CSP** with `default-src 'none'`, the stylesheet pinned by hash, `data:` images and media only, and no scripts.                                                                                                                                                                                                                                                       | Even a buggy or modified renderer can't make the page phone home or run code.                                                                                                                                                                                                                                                      |
| 9   | **The viewer opens external links in a new tab** (`target="_blank" rel="noopener noreferrer"`); static pages use `rel="noopener noreferrer"` only.                                                                                                                                                                                                                                          | The embedded viewer must not navigate its host application away. A static page is the whole application.                                                                                                                                                                                                                           |
| 10  | **Workspace packages build before typecheck and tests** (CI and `pnpm check`).                                                                                                                                                                                                                                                                                                              | Packages consume each other's built output. This is the standard monorepo order, and it avoids path-mapping tricks.                                                                                                                                                                                                                |

## Evidence

- **Unit tests (221):** sanitization, link rewriting, token parity between the viewer and core, a ZIP reader that agrees with core and refuses bombs, and a byte-for-byte HTML round trip for all 24 valid fixtures.
- **Browser tests (285 on Chromium):**
  - every valid fixture renders;
  - a 4-width × 2-theme layout matrix with no horizontal overflow;
  - isolation from a hostile host page, and offline loading;
  - all 98 hostile and invalid fixtures neutralized, with no requests and no dialogs;
  - static pages readable with JavaScript off;
  - axe WCAG 2.2 AA: 0 violations;
  - the plain-HTML example.
- **Mutation check:** a sanitizer deliberately broken to keep `on*` attributes is caught by the hostile-fixture tests.
- **Firefox and WebKit** run in CI (`e2e.yml`); this build session only has Chromium.
